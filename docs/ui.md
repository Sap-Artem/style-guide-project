# Элементы интерфейса

Пользователь сверяет текст инструкции с экраном, поэтому названия элементов интерфейса должны совпадать с экраном дословно.

## Правила

- **ИНТ-1.** Названия кнопок и разделов выделяем жирным и пишем как на экране, путь по меню – через «→».
- **ИНТ-2.** Используем глаголы «нажмите», «выберите», «введите»; «кликните» и «тапните» не используем.

## Пример

Чтобы включить тёмную тему, откройте **Профиль → Настройки → Тема** и выберите **Тёмная**.
