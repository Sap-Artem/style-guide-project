# Разметка Markdown

Исходные тексты документации хранятся в Markdown и собираются в сайт с помощью MkDocs.
Часть правил раздела проверяет линтер markdownlint.

## Правила

- **MD-1.** В файле один заголовок первого уровня, уровни заголовков не пропускаем.
- **MD-2.** Заголовки пишем без точки в конце; нумеруем их только в документах по ГОСТ.
- **MD-3.** Маркер списка – `-`; вложенные пункты сдвигаем на 4 пробела, иначе MkDocs их не распознает.
- **MD-4.** Код и команды – в обратных кавычках, блоки кода – с указанием языка.
- **MD-5.** Текст ссылки говорит, куда она ведёт: «см. [Глоссарий](terminology.md)», а не «[здесь](terminology.md)».
- **MD-6.** Примечания оформляем блоком `!!! note`, а не жирным текстом прописными буквами.
- **MD-7.** Имена файлов – латиницей, слова через дефис: `user-guide.md`.

## Пример

```markdown
## Шаги

1. Откройте вкладку **Транзакции**.
2. Выберите категорию.
    - Если нужной категории нет, нажмите **Новая категория**.

!!! note "Офлайн-режим"
    Без сети расход сохранится на устройстве и отправится на сервер позже.
```

Так пример выглядит на сайте:

!!! note "Офлайн-режим"
    Без сети расход сохранится на устройстве и отправится на сервер позже.
