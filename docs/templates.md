# Шаблоны документов

Новый документ создаётся из шаблона, в котором уже есть обязательные разделы.

| Вид документа | Обязательные разделы |
| --- | --- |
| README | Назначение проекта, быстрый старт, структура репозитория |
| Описание метода API | Назначение, запрос, пример запроса, ответ и коды ошибок |
| Инструкция пользователя | Что позволяет сделать, перед началом, шаги, результат |
| Техническое задание | Разделы по ГОСТ 34.602-2020 |

## Шаблон инструкции пользователя

```markdown
# Как <действие>

<Что позволяет сделать инструкция – одно предложение.>

## Перед началом

- <Условие, например: «Вы вошли в приложение.»>

## Шаги

1. <Действие в повелительном наклонении.>
2. <Действие.>

## Результат

<Что увидит пользователь после выполнения шагов.>
```
