# Терминология и глоссарий

Один объект во всех документах называется одним термином.

## Правила

- **ТРМ-1.** Один объект называем одним термином из глоссария.
- **ТРМ-2.** Названия технологий пишем в оригинале и не склоняем: PostgreSQL, GitHub, MkDocs.
- **ТРМ-3.** Сокращение расшифровываем при первом упоминании: «программа и методика испытаний (ПМИ)».
- **ТРМ-4.** Если у англицизма есть привычный русский вариант, используем его: «офлайн-режим», «ветка», «интерфейс».
  Названия технологий и паттернов (Offline-first, Pull Request) не переводим.
- **ТРМ-5.** С прописной буквы в середине предложения пишем только роли и сущности из ТЗ: Заказчик, Разработчик, Система.

## Глоссарий

| Термин | Не используем |
| --- | --- |
| транзакция | операция, запись, трата |
| счёт | кошелёк, аккаунт |
| офлайн-режим | Offline, автономный режим |
| хеширование | хэширование |
| Разработчик (в ТЗ) | Исполнитель |
| пользователь | клиент, юзер |
| нажать | кликнуть, тапнуть |

Новые термины добавляются в глоссарий через Pull Request.
