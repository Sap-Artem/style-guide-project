# Стиль изложения

Документация говорит с читателем вежливо и по делу.
Читатель приходит в документацию, чтобы решить задачу, поэтому текст должен быть коротким и однозначным.

## Правила

- **СТЛ-1.** В инструкциях для пользователей обращаемся на «вы», в ТЗ и технических документах пишем безлично: «Система должна сохранять транзакцию».
- **СТЛ-2.** Одна мысль – одно предложение, не длиннее 25 слов.
- **СТЛ-3.** Пишем в активном залоге.
- **СТЛ-4.** Избегаем канцелярита.
- **СТЛ-5.** Требования формулируем с измеримым критерием.
- **СТЛ-6.** Не используем оценочные слова и восклицания: «легко», «просто», «к сожалению».

## Примеры

| Правило | Неправильно | Правильно |
| --- | --- | --- |
| СТЛ-3 | Токен проверяется сервером. | Сервер проверяет токен. |
| СТЛ-4 | Осуществляется проверка лимита. | Система проверяет лимит. |
| СТЛ-5 | Приложение должно быстро запускаться. | Приложение запускается не более чем за 3 с. |
| СТЛ-6 | Добавить расход очень просто! | Чтобы добавить расход, нажмите **Добавить**. |
