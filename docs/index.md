# Стайлгайд документации «ФинМетрика»

Стайлгайд задаёт правила написания и оформления документации проекта [«ФинМетрика»](https://github.com/Sap-Artem/finmetrica-backend).
Он распространяется на README, техническое задание, описания методов API и инструкции для пользователей.

## Как пользоваться

- У каждого правила есть код, например `ОРФ-3`.
  На ревью достаточно сослаться на код правила.
- Новый документ создавайте из [шаблона](templates.md).
- Если правило мешает или чего-то не хватает, предложите изменение через Pull Request.
