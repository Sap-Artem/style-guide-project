# Доступность текста

Документацию читают люди с разным зрением, на разных экранах и с помощью программ экранного доступа.
Правила раздела помогают сделать текст понятным для всех.

## Правила

- **ДОС-1.** У каждого изображения есть альтернативный текст, который передаёт его смысл: `![Экран добавления расхода](images/add-expense.png)`.
- **ДОС-2.** Не передаём смысл только цветом или положением на экране: «нажмите **Сохранить**», а не «нажмите зелёную кнопку справа».
- **ДОС-3.** Заголовки отражают содержание раздела, чтобы по ним можно было перемещаться без чтения всего текста.
- **ДОС-4.** Термин, которого нет в [глоссарии](terminology.md), поясняем при первом упоминании или добавляем в глоссарий.
- **ДОС-5.** В таблицах документов Word (например, ТЗ) есть строка заголовков, объединённые ячейки не используем.
  В Markdown строка заголовков обязательна по синтаксису, а объединять ячейки нельзя.
- **ДОС-6.** Если действие выполняется жестом, указываем и другой способ: «проведите влево или нажмите **Удалить**».
