# style-guide-project

Стайлгайд документации проекта [«ФинМетрика»](https://github.com/Sap-Artem/finmetrica-backend).

Сайт стайлгайда: <https://sap-artem.github.io/style-guide-project/>

## Локальная сборка

Установите зависимости командой `pip install mkdocs-material` и запустите `mkdocs serve`.
Сайт откроется по адресу <http://127.0.0.1:8000>.
